# 一次性令牌登录与企业版 v2

- 状态：STORY-01.1 已完成，STORY-02 待领取

- 负责人：dsh-auth 产品与工程团队

## 项目一览

本项目把 dsh-auth 从单账号插件升级为企业版管理员认证，并用项目自带的固定版本 Caddy 取代对主机 Nginx 的依赖。云托管商可以通过实例内命令签发短期、一次性登录链接。用户兑换链接后获得与密码登录相同的 72 小时滚动会话，并可在首次登录时设置管理员用户名和密码。

这是一次破坏性 v2 升级。旧参数、旧安装状态和旧会话不迁移。实施先建立统一认证状态，再验证标准 Caddy，随后完成安装器、令牌签发、浏览器兑换、管理员初始化和全量安全验收。

项目负责人先看[《项目进展》](./项目进展.md)，了解当前门禁和下一步。

需要多人加速时，再看[《后续并行安排》](./并行安排.md)。它规定可并行支线、接口冻结点和合并顺序。

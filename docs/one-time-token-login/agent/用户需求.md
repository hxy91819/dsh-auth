# 用户需求

## 背景与角色

`dsh-auth` 当前为 DeepSeek Harness 提供单账号密码登录。项目进入企业产品后，需要允许已经在云控制台完成实例所有权认证的用户免密进入实例，同时保留实例内管理员密码作为独立登录方式。

| 角色 | 目标 | 权限边界 |
| --- | --- | --- |
| 云控制面 | 通过带内命令取得短期登录材料并构造控制台链接 | 不持有或设置实例管理员密码 |
| 实例内签发者 | 在受控系统或容器内签发 bearer token | systemd 为 root；容器为 root 或认证状态唯一所有者 |
| 实例管理员 | 点击控制台链接进入 Harness，并建立或使用管理员凭据 | 令牌只映射固定管理员，不携带云用户身份 |
| 实例运维者 | setup、doctor、重置密码、卸载和处理升级 | 必须看到明确计划、诊断、权限和破坏性升级说明 |

## 核心旅程

### 密码初始化

运维者在 setup 中显式选择 `password`，提供管理员用户名和安全密码来源。安装完成后，用户可用密码登录；若同时启用令牌，云控制台也能持续签发免密登录链接。

### 令牌初始化

运维者在 setup 中显式选择 `login-token` 并启用令牌，不提供用户名或密码。云控制面执行签发命令，用户点击带 fragment token 的 URL。兑换成功后先获得管理员会话，再看到设置用户名和密码的提示。

用户可以完成设置，也可以选择 Later。本次 Later 直接进入原 returnTo，不写提醒时间；下次新的令牌登录再次提示。管理员未设置时，令牌会话临时使用用户名 `admin`，密码登录不可用。

### 日常控制台登录

管理员凭据建立后，令牌能力仍按 setup 配置长期保留。每个命令只签发一个最多五分钟、一次性使用的 token。成功兑换后会话与密码登录完全一致：72 小时期限、空闲过期、滚动续期、服务端撤销和安全 Cookie。

### 失败体验

格式错误、过期、已使用和不存在的 token 显示同一失败页，不能提示攻击者具体状态。页面默认提供中英文友好文案；setup 可以分别覆盖中文和英文纯文本。用户仍可返回管理员密码登录；管理员未设置时文案引导其重新从云控制台发起。

## 功能需求

| ID | 需求 |
| --- | --- |
| UR-01 | 固定管理员内部 ID 和角色为 `admin`，允许用户名和密码后设 |
| UR-02 | setup 显式选择密码或令牌初始化，并显式启停长期令牌能力 |
| UR-03 | systemd 与容器使用同一签发结果和安全语义 |
| UR-04 | token 默认 300 秒，可缩短至 60 秒，最多 32 个有效 token 并存 |
| UR-05 | 每个 token 至多兑换一次，并发、重启和失败不能产生重放窗口 |
| UR-06 | URL 一次点击完成 fragment 清理、同源 POST 和会话建立 |
| UR-07 | 令牌会话复用正常会话策略和受保护资源边界 |
| UR-08 | 首次令牌用户可设置用户名和密码，也可选择 Later |
| UR-09 | 管理员首次设置并发安全，成功后保留当前会话并撤销其他启动会话 |
| UR-10 | 旧 v1 参数和状态得到明确拒绝与重装指引，不自动迁移 |
| UR-11 | 一个 `dsh-auth` 主包自带固定 Caddy，不要求用户再安装其他包、配置或交出已有网关 |
| UR-12 | automatic/manual TLS、x64/ARM64 和离线安装具有同一认证边界 |

## 安全与质量需求

- token、完整登录 URL和密码不得进入 argv、环境、计划、诊断、错误、日志、Git、fixture 或持久元数据。
- token 明文只允许出现在成功签发 stdout/JSON、浏览器 fragment、兑换 POST 和短暂进程内存。
- 所有状态路径、文件类型、真实路径、所有权、权限和大小先校验后使用。
- 兑换和管理员设置必须执行同源、CSRF、safe returnTo、no-store、内容安全策略和请求大小限制。
- 运行期状态更新必须原子、可恢复；安全失败优先失效 token，不优先可用性。
- 测试验证浏览器、HTTP、CLI、磁盘权限和重启后的可观察结果。

## 非目标

- 普通用户、多管理员、云用户身份映射或角色同步。
- 浏览器内修改已经建立的管理员密码。
- 审计查询后台、厂商品牌 HTML、外部失败跳转链接。
- v1 自动迁移、保留旧会话或兼容旧 CLI/配置别名。
- 修改 Harness 源码、探测 DOM、重写静态资源或绕过项目受管 Caddy 公网边界。
- 复用系统 Caddy/Nginx、自研通用 Go Gateway 或在本期支持 Caddy 插件生态。
- 把 Caddy 拆成需要单独发布、安装或归档的平台 npm 包。

# STORY-05：交付管理员首次初始化

## 愿景

令牌初始化部署无需由云平台预置实例密码。首位获授权用户可以设置管理员用户名和密码，也可以选择 Later 后先使用 Harness。

## 范围

在令牌兑换成功且管理员未配置时显示独立初始化页。实现用户名和密码规则、二次确认、Later、并发保护、会话清理和后续密码登录。既有密码的浏览器修改不在本期。技术路径见[执行卡](../agent/STORY-05-交付管理员首次初始化执行卡.md)。

## 解决方案概览

- 未配置管理员的令牌会话先使用临时用户名 `admin`。
- 每次新的令牌登录都提示设置；Later 只跳过当前登录。
- 首次设置在认证状态内原子完成，只有一个并发请求成功。
- 设置成功后保留当前会话并撤销其他启动会话。

## 验收标准

- 用户名经 NFC 后为 1–64 字符，区分大小写，拒绝控制字符和首尾空白。
- 密码为 15–128 个 Unicode 字符且不超过 1024 字节，不做规范化和组合规则检查。
- Later 不写延期状态，直接进入安全 returnTo；下次令牌登录再次提示。
- 并发提交只有第一个建立凭据，其他请求不能覆盖并获得友好结果。
- 凭据建立后当前会话继续有效、用户名立即更新，其他启动会话失效，密码登录可用。

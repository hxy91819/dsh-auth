# STORY-01：建立统一管理员认证状态

## 愿景

让管理员身份、密码状态和会话由一个可恢复的服务端状态管理。后续令牌登录和首次设置凭据不再依赖启动时只读的单账号配置。

## 范围

固定内部管理员 ID 和角色为 `admin`，建立服务拥有的认证状态文件，支持未设置和已设置管理员凭据两种状态，并让所有会话读取当前管理员用户名。令牌签发、HTTP 兑换和安装器接线留给后续 Story。技术细节见[执行卡](../agent/STORY-01-建立统一管理员认证状态执行卡.md)。

## 解决方案概览

- 用一个受权限保护的认证状态保存管理员凭据和持久会话。
- 会话只保存认证方法和时间，不复制可变用户名。
- 管理员未配置时使用临时用户名 `admin`，但密码登录不可用。
- 状态写入采用原子替换；格式、权限或秘密不一致时启动失败。

## 验收标准

- 状态文件只允许普通文件、预期所有者和 `0600` 权限，写入失败不留下部分状态。
- 管理员 ID 与角色始终为 `admin`；用户名未设置时对令牌会话显示 `admin`。
- 密码未设置时不能通过密码登录；设置成功后现有会话读取新用户名。
- 并发首次设置只有一个成功；成功者可保留当前会话并撤销其他启动会话。
- 密码和令牌会话均保持现有过期、续期、容量、撤销和重启恢复结果。
